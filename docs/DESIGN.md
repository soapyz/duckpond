# 鸭塘 DuckPond · 产品规划 v1（鸭子主题版）

> 一句话定位：一个常驻托盘的 Windows 自律小工具——**定时提醒你休息、用番茄钟记录专注，把每次专注孵成一只小鸭养在塘里，再用周/月看板把"坚持"变成看得见的成就感。**

工作名暂定 **鸭塘（DuckPond）**，可执行体 `DuckPond.exe`，纯本地、无账号、无联网依赖。

## 二、功能蓝图

| 模块 | 能力 | 关键细节 |
|---|---|---|
| ⏰ **定时休息** | 多规则自定义提醒（一次性/每天/每周指定几天/每 N 分钟） | 例如「10:15 休息 10 分钟」；提前 30 秒出"准备休息"轻提示；支持推迟 5 分钟、跳过、提前结束 |
| 🍅 **番茄钟** | 专注 25′ / 短休 5′ / 长休 15′，可改时长、可自动衔接 | 专注时可填任务标签；一轮结束自动进入下一段；计时用单调时钟，休眠唤醒不漂移 |
| 🌫️ **专注遮罩**（参考 fadetop） | 休息开始时桌面降模糊 + 压暗，浮出倒计时与小鸭 | 抓屏 → 快速高斯近似模糊 → 300ms 淡入；点击退出（记为"跳出"）；休息期间键鼠活动不影响遮罩 |
| 🦆 **鸭塘养成**（参考 Forest，主题改为鸭子） | 每次完整专注孵出 1 只小鸭，中途中止 → 鸭子飞走、塘边留灰影 | 每只鸭按自身累计专注时长成长（鸭苗→小鸭→成年鸭）；鸭种随连续天数解锁；结算页做"破壳"小动画 |
| 🏅 **成就系统** | 鸭群数量、连续天数、累计小时、无跳出周、早起/深夜专注等徽章 | 徽章墙 + 里程碑进度条，达成时轻庆祝动画；达成后解锁塘边装饰 |
| 📊 **周/月看板** | 今日概览、7 日柱状、月热力图、时段分布、跳出记录、上周对比 | GitHub 风格贡献热力图；可导出 PNG 卡片晒成就 |
| 🧩 **系统集成** | 托盘常驻、右键菜单、开机自启、全局快捷键、单实例、本地库 | `Ctrl+Alt+R` 立即休息；数据存 `%AppData%\DuckPond\duckpond.db`，每日自动备份 |

**明确不做**：云同步、账号、手机端、复杂待办管理、强制锁屏、家长控制。

## 三、鸭子玩法设定（替代原森林）

| 维度 | 设定 |
|---|---|
| **出生** | 专注开始 → 塘里出现一枚鸭蛋；专注完成 → 蛋裂开，小鸭探头（1 秒动画 + 一声"嘎"）。中途放弃 → 蛋碎掉，连小鸭都没孵出来，塘边留一片羽毛 |
| **成长** | 每只鸭单独累计专注分钟：`0–60′ 鸭苗` → `60–180′ 小鸭` → `180′+ 成年鸭`（体型变大、羽毛变亮、会自己游圈） |
| **鸭种解锁** | 3 天连续 → 戴草帽鸭；7 天 → 带游泳圈鸭；14 天 → 墨镜鸭；30 天 → 金鸭；单次 ≥90′ → 马拉松鸭；早 7 点前专注 → 早起鸭；23 点后 → 夜猫鸭 |
| **中断惩罚** | 中止的专注 → 塘边出现一只灰色鸭子剪影 + 羽毛，标注日期。灰影不删除、可点开看原因，作为"逃鸭数"进看板；连续 3 次跳出触发提醒"鸭塘要荒了" |
| **塘的规模** | 0–9 只 小水洼；10 只 池塘；30 只 带芦苇和睡莲的塘；80 只 湖；每级换一次背景和音效，升级有全屏庆祝 |
| **生命力** | 鸭子会在塘里缓慢游动、偶尔潜水、点它会"嘎"一声（可静音）；休息遮罩上就显示当前正在孵的那只小鸭 |
| **不做** | 不做投喂/喂食体力系统（容易变成负担），不做鸭子社交/互访，首版不引入货币 |

## 四、典型一天的交互

1. **09:00** 开机自启，托盘出现一只小鸭图标，气泡提示"今天目标 4 小时"。
2. **09:05** 双击托盘打开主窗，点「开始专注 · 写方案」→ 25 分钟倒计时，塘里落下一枚蛋。
3. **09:30** 专注完成 → 蛋裂开、小鸭入塘（+25 分钟），自动进入 5 分钟短休；桌面变模糊，中央是倒计时和这只刚孵出的小鸭。
4. **10:15** 定时规则触发"休息 10 分钟"→ 提前 30 秒右下角浮出提示，10:15 遮罩淡入。
5. **10:25** 遮罩淡出，提示"休息完成，回来吧"，本次休息计入"休息达成率"。
6. **18:00** 收工打开看板：今日 3h40m、9 只鸭、1 只逃走、连续 12 天；本周柱状比上周 +23%。

## 五、技术方案

### 选型（已确认）

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| **WPF 壳 + WebView2 界面** | 原生系统能力（托盘/顶置/全局热键/自启/抓屏）稳；界面用 HTML/CSS 做得漂亮、图表动画成本低 | 需维护 C#↔JS 消息桥；静态页内存约 80–120MB | ✅ 主方案 |
| 纯 WPF/XAML | 单技术栈、启动快 | 卡片/热力图/动画手写代价高 | 备选 |
| Python + PySide6 | 写起来快 | 托盘/遮罩/自启稳定性较差，需额外装包 | 不采用 |

### 结构

```
DuckPond.exe (WPF 宿主进程，常驻托盘)
├── Core      调度引擎 / 番茄状态机 / 鸭塘与成就规则 / SQLite 仓储
├── Overlay   全屏顶置窗口：抓屏 → 模糊 → 淡入淡出（原生，不用 WebView）
├── Tray      托盘图标与菜单、全局热键、开机自启、单实例
└── UI(WebView2)  鸭塘 / 看板 / 设置，本地 wwwroot，postMessage 双向通信
```

### 几个必须做对的技术点

| 点 | 做法 |
|---|---|
| 模糊遮罩 | `BitBlt/Graphics.CopyFromScreen` 抓全屏 → 降采样到 1/8 → 双三次放回 → 3px 盒式模糊 + 35% 黑色压暗，单帧 <80ms |
| 顶置不被抢 | 窗口 `Topmost` + `WS_EX_TOOLWINDOW`，每 200ms 校正位置；按虚拟屏全尺寸覆盖任务栏 |
| 计时精度 | 单调时钟（Stopwatch）+ 落库用本地时间；合盖/休眠恢复后按单调差值补算 |
| 通知 | 自绘无边框提示窗（右下角滑入），不依赖系统 toast 注册 |
| 全屏场景保护 | 检测前台窗口是否全屏（游戏/演示），命中则把本次提醒自动推迟 N 分钟 |
| 鸭塘渲染 | WebView2 内用 Canvas 绘制水面与鸭子（矢量鸭 + 轻微游动轨迹），鸭子数量多时限制同屏 40 只并分池展示，避免掉帧 |
| 数据 | SQLite 单文件 + 每日凌晨 JSON 备份；升级不丢历史 |
| 打包 | `dotnet publish` 框架依赖（本机已有 .NET 10），输出 exe + wwwroot + 图标，约 10–20MB |

### 数据模型（初版）

| 表 | 主要字段 |
|---|---|
| `sessions` | id, kind(focus/rest), planned_sec, actual_sec, start_at, end_at, status(完成/中止/跳过), task_label, source(pomodoro/schedule), aborted_by(点击退出/系统) |
| `ducks` | id, species, stage, born_at, alive, session_id, pond_slot, focused_sec, escape_reason |
| `schedules` | id, mode(once/daily/weekly/interval), time, weekday_mask, interval_min, rest_sec, style, enabled, label |
| `achievements` | id, key, unlocked_at, progress |
| `settings` | key, value（主题、默认时长、遮罩强度、鸭叫开关、自启…） |

## 六、分期实施计划（每期都可独立验收）

| 期 | 内容 | 验收标准 | 预估 |
|---|---|---|---|
| **P0 骨架** | 项目结构、编译脚本、托盘常驻、单实例、设置读写、SQLite 建库、开机自启 | 双击 exe 出现托盘小鸭图标，右键能退出；重启后自启；库文件正常生成 | 1 轮 |
| **P1 计时核心** | 番茄状态机 + 定时规则引擎 + 自绘提醒窗 + 暂停/推迟/跳过 | 配一条「10:15 休息 10 分钟」，10:14:30 出提示、10:15 触发、10:25 结束并正确落库 | 2 轮 |
| **P2 遮罩** | 抓屏模糊、淡入淡出、顶置保持、点击退出、全屏保护 | 遮罩盖住任务栏；淡入 <400ms 无撕裂；点一下能退且记一次跳出；游戏中不被打断 | 2 轮 |
| **P3 鸭塘** | 蛋→孵化的出生动画、鸭子游动、成长阶段、逃鸭灰影、塘的规模升级 | 完成一次 25′ 多 1 只活鸭；中途放弃留下 1 只灰影；累计到 10 只时塘升级有庆祝 | 3 轮 |
| **P4 看板** | 今日/周/月视图、热力图、时段分布、跳出次数、对比上周、导出卡片 | 数字与 session 明细对得上；周/月切换无错位 | 2 轮 |
| **P5 成就与打磨** | 鸭种解锁、徽章、里程碑动画、主题、快捷键、首次引导、打包 | 达成条件即时解锁；冷启动 <2s；提供 exe + 使用说明 | 2 轮 |

交付物：`DuckPond.exe`（可直接运行）+ `使用说明.md` + 数据备份位置说明。

## 七、风险与对策

| 风险 | 对策 |
|---|---|
| Win11 上顶置窗口被其他 topmost 抢到下面 | 周期性校正 + 置顶层合并；提供"重新置顶"热键 |
| 鸭子多到几十只后画面杂乱、掉帧 | 同屏上限 + 分区水塘 + 卡片式"鸭册"列表视图，二维/一维都能看 |
| 抓屏模糊吃 CPU | 降采样路径固定；多屏时每屏一张位图 |
| 提醒被无视、点击退出变成习惯 | 记录跳出率，连续跳出时提高提醒力度；提供安静时段与单日提醒上限 |
| 数据只有本地 | 每日自动备份 + 设置页一键导出/导入 |
| 功能越加越肿 | P0–P5 先做完整闭环；投喂、鸭币、社交放二期 |

## 八、已确认的三件事（2026-11-20 定稿）

| 决策点 | 结论 |
|---|---|
| 界面技术 | ✅ WPF 壳 + WebView2 前端 |
| 休息强制等级 | ✅ 遮罩 + 点击可退出（记录跳出次数） |
| 首版范围 | ✅ 完整闭环 P0–P5 |
| 养成主题 | ✅ 树 → 鸭子（鸭塘，含孵化/逃走/成长/鸭种解锁） |

对应调整：遮罩需接收鼠标点击，窗口不能用点击穿透样式；点击退出写入 `sessions.aborted_by`，当周看板单列"跳出次数"与"逃鸭数"。
