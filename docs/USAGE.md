# 🦆 鸭塘 DuckPond · 使用说明

一个只给自己用的 Windows 自律小工具：**定时提醒休息 + 番茄钟 + 桌面模糊遮罩 + 鸭子养成 + 周/月看板**。

![主界面](DuckPond/shot-final-focus.png)

## 🚀 怎么运行

| 项目 | 说明 |
|---|---|
| 启动 | 双击 `鸭塘\DuckPond.exe`（绿色免安装，已自带 .NET 运行时） |
| 首次启动 | 默认两条定时休息：每天 **10:15** 与 **15:30**，各休 10 分钟，带遮罩 |
| 关闭窗口 | 不是退出，是**缩到托盘**继续计时；真要退出请用托盘右键 → 退出 |
| 开机自启 | 默认开启（托盘静默启动），可在设置里关掉 |
| 单实例 | 重复双击 exe 只会把已有窗口唤到前面，不会开第二个 |

> 建议把 `鸭塘` 整个文件夹放到固定位置（例如 `D:\Tools\鸭塘`）。移动后重新双击一次，开机自启路径会自动跟着改。

## 🧭 四个页面

| 页面 | 能做什么 |
|---|---|
| ⏱ 专注 | 圆环倒计时、15/25/45/60 分钟预设、任务名、开始/暂停/结束、今日目标进度、今天的节奏卡片 |
| 🦆 鸭塘 | 完成专注孵出的小鸭在水面游动，点鸭子会叫；鸭册记录每只鸭；「飞走的鸭」记录未完成的中断 |
| 📊 看板 | 今日/本周/累计/连续天数、最近 7 天柱图、一天中的专注时段、本月热力图、成就墙、导出今日打卡图 |
| ⚙ 设置 | 番茄钟参数、遮罩强度、全屏顺延、定时休息规则（增删改）、开机自启、每日目标、打开数据目录 |

## ⌨️ 快捷键 & 托盘

| 操作 | 效果 |
|---|---|
| `Ctrl+Alt+R` | 立即休息 5 分钟（弹遮罩） |
| `Ctrl+Alt+P` | 开始 / 暂停专注 |
| `Ctrl+Alt+D` | 打开 / 收起面板 |
| 托盘右键 | 打开面板、开始专注、休息 5 分钟、暂停提醒、开机自启、退出 |

## ⏰ 自定义定时休息（例：10:15 休 10 分钟）

1. 打开 **设置 → 定时休息**
2. 在「新增一条提醒」里填：方式 `每天`、时间 `10:15`、休息 `10` 分钟、名称 `上午休息`
3. 勾选「用模糊遮罩休息」→ 点 **添加规则**
4. 已有规则可随时 `编辑` / 开关 / `删除`；右上角「暂停提醒」可临时全部停掉（例如休假）

方式支持四种：每天、每周指定几天、仅一次（指定日期时间）、每隔 N 分钟。

## 🌫 遮罩怎么工作

- 到了休息时间，先抓一张当前屏幕 → 强模糊 + 压暗，全屏盖住（连任务栏一起盖）
- 中间是大倒计时 + 鸭子 + 一句提示，300ms 淡入
- **点任意处或按 ESC 可提前结束**，这次会记成「跳出遮罩」一次，不扣鸭
- 设置里可调遮罩强度（默认 55%）、预览 30 秒
- 全屏开会/看视频时，默认**顺延**（默认 10 分钟）而不是打断你，可在设置关掉

## 🍅 番茄钟规则

| 参数 | 默认 | 说明 |
|---|---|---|
| 专注 | 25 分钟 | 预设按钮可快速改 |
| 短休 | 5 分钟 | 每段专注后 |
| 长休 | 15 分钟 | 每 4 段后 |
| 自动接续 | 开 | 一段结束自动进下一段 |

- 专注中关闭/切走窗口不算失败，**倒计时按真实时间走**（最小化也不停）
- 主动点「结束」= 放弃这段：这只鸭会飞走，塘里留一个灰色影子，看板记为「中断」

## 🐣 鸭子怎么长

| 阶段 | 条件（累计专注时长） |
|---|---|
| 🥚 蛋 → 🐤 鸭苗 | 完成一次专注就孵出 |
| 🐤 鸭苗 → 🦆 小鸭 | 单只累计 ≥ 60 分钟 |
| 🦆 小鸭 → 成年鸭 | 单只累计 ≥ 180 分钟 |

- 每只鸭按专注时长随机一个「鸭种」：普通黄鸭、草帽鸭、游泳圈鸭、墨镜鸭、金鸭、马拉松鸭、早起鸭、夜猫鸭
- 鸭子数量决定塘的等级：小水洼 → 池塘 → 芦苇塘 → 鸭湖，页面顶部有升级进度
- 10 个成就（第一只鸭、鸭群初成、鸭塘热闹、十小时、五十小时、三日不断、一周坚持、半月不辍、满月、无逃鸭期）

## 📊 看板与打卡图

- **本月热力图**：颜色越暖代表当天专注越久，鼠标悬停看具体时长
- **一天中的专注时段**：看自己到底在几点最能坐住（近 30 天）
- **导出今日打卡图**：一键生成 1000×1400 的 PNG，存到数据目录 `exports\`，可直接发朋友圈/群里打卡
- 看板数据全部来自本地记录，不联网、不上传

## 💾 数据、备份、迁移

| 项目 | 位置 |
|---|---|
| 数据文件 | `%AppData%\DuckPond\data.json` |
| 自动备份 | `%AppData%\DuckPond\backups\data-YYYYMMDD.json`（保留最近 14 天） |
| 导出图片 | `%AppData%\DuckPond\exports\` |
| 缓存 | `%AppData%\DuckPond\WebView2\`（可删，删了会重新建） |

- 设置页有「打开数据文件夹」按钮
- 换电脑：退出程序 → 复制整个 `DuckPond` 数据目录 → 放到新机器同路径即可
- 写入是「先写临时文件再替换」，程序崩了也不会写坏原数据

## ❓ 常见问题

| 现象 | 处理 |
|---|---|
| 遮罩没弹出来 | 设置 → 定时休息，确认规则是开启状态、右上角不是「恢复提醒」；全屏应用可能触发顺延 |
| 时间到了但只弹了小提醒条 | 该规则没勾「用模糊遮罩休息」 |
| 双击没反应 | 已经在托盘运行了，点托盘图标即可；或看任务管理器是否已有 DuckPond |
| 想要更狠的强制休息 | 目前刻意保留「点击可退出」，跳出次数会记在数据里；不建议做到无法退出 |
| 托盘图标不见了 | Windows 托盘折叠区里找，拖到任务栏常驻 |

## 🗑 卸载

1. 托盘右键 → 退出
2. 设置里先关「开机自动启动」
3. 删除 `鸭塘` 文件夹与 `%AppData%\DuckPond` 即可，注册表只留 HKCU Run 一项（关自启时会自动删）
